# Dino Runner Bot — NEAT

Нейроэволюционный агент ([NEAT](https://neat-python.readthedocs.io/)), который играет
в [T-Rex Runner](https://wayou.github.io/t-rex-runner/) в настоящем Chromium.
Обучение полностью асинхронное: популяция распределяется по пулу из 15 независимых
браузеров, каждый геном играет эпизод в своём браузере.

## Что внутри

- [`dino.py`](dino.py) — весь бот: JS-агент для страницы, пул браузеров,
  оценка геномов, цикл NEAT, чекпоинты и журнал.
- [`evaluate.py`](evaluate.py) — проверка сохранённого генома на нескольких
  независимых сидах без обучения.
- [`neat_config.ini`](neat_config.ini) — конфигурация NEAT (19 входов, 2 выхода).
- [`game_source.js`](game_source.js) — исходный код игры T-Rex Runner
  (использован для подбора нормализации признаков и параметров среды).

## Как это работает

**Агент живёт внутри страницы.** Нейросеть переносится в JavaScript
([`network_to_js()`](dino.py:584)), поэтому на каждый игровой кадр нет сетевого
round-trip Playwright — решение принимается в том же JS-контексте, где идёт игра.

**Детерминированная быстрая симуляция.** Вместо requestAnimationFrame игра
продвигается вручную фиксированным шагом 1/60 c: `performance.now()` замораживается
на виртуальных часах, `runner.update()` вызывается в цикле
([`simulate()`](dino.py:389)). Эпизод считается за десятки миллисекунд вместо
десятков секунд, а физика полностью воспроизводима.

**Сеяная трасса.** `Math.random` подменяется детерминированным ГПСЧ (mulberry32),
поэтому все геномы одного поколения играют **одну и ту же** трассу
(`--route-seed`). Это убирает шум при сравнении геномов и расхождение train/eval.

Учтено, что `Horizon.reset()` самой игры не очищает `clouds` и `obstacleHistory`:
облака тянут `Math.random()` и сдвигали бы поток ГПСЧ, поэтому горизонт сбрасывается
полностью.

## Признаки (19 входов)

Расстояния нормируются на рабочее окно реакции (~160 px), а не на всю ширину
канваса, — иначе полезный диапазон сжимался в 0.15–0.27 и сеть его «не видела».
Дополнительно подаются размеры препятствия, высота/ширина динозавра, скорость и
признак приседа.

## Награда (fitness)

```
useful_share = 1 - useless_jumps / jumps
fitness = score * (0.3 + 0.7 * useful_share) + 0.02 * frames - 0.6 * useless_jumps
```

Прыжок считается **бесполезным** физически: динозавр приземлился, но под ним так и
не прошло препятствие. Такой штраф не зависит от скорости (фиксированный порог в
пикселях на высокой скорости давал ложные срабатывания) и убирает «прыжки-спам».
За выживание до лимита эпизода (`TIME`/`FRAMES`) начисляется бонус.

## Окна браузеров

По умолчанию все браузеры запускаются **headless** — окон не видно, и это
намеренно: так 15 Chromium не конкурируют за отрисовку и обучение идёт быстрее.
Чтобы видеть игру, нужен флаг `--headed`:

```bash
uv run python dino.py --eval --headed          # показать игру (окно откроется)
uv run python dino.py --headed --generations 10
uv run python evaluate.py best_genome.pkl --headed
```

В режиме `--eval` окно открывается всегда (флаг `--headed` не нужен).
`--live` в [`evaluate.py`](evaluate.py) тоже включает видимое окно автоматически.

## Запуск

```bash
# обучение: 15 браузеров Chromium, 40 поколений
uv run python dino.py --browsers 15 --generations 40 --population 200 \
    --episode-seconds 120 --max-frames 7200

# видеть все 15 окон во время обучения
uv run python dino.py --headed --generations 10

# только играть сохранённым геномом (реальное время, с анимацией)
uv run python dino.py --eval

# воспроизвести один и тот же прогон вживую (фиксированный сид трассы)
uv run python dino.py --eval --eval-seconds 60 --route-seed 12345

# продолжить с чекпоинта
uv run python dino.py --resume neat-checkpoint-10

# проверить геном на нескольких невиданных сидах
uv run python evaluate.py best_genome.pkl --seeds 12345 777 424242 --max-frames 36000
```

Если окно не появляется:

- запущен `--eval` или `--headed` (без них браузер headless);
- проверить установку Chromium: `uv run playwright install chromium`;
- проверить, что сайт игры доступен: `https://wayou.github.io/t-rex-runner/`
  (игра грузится с сети, офлайн-копии в проекте нет).

> Режим `--eval` использует тот же фиксированный шаг 1/60 c, что и тренировка,
> поэтому его результат побитово совпадает с [`evaluate.py`](evaluate.py) на том
> же сиде. requestAnimationFrame только разносит кадры по экранному времени.

## Результаты

Детерминированная симуляция ускоряет поколение примерно в 40 раз: ~0.3–1.1 c
против ~10 c на реальном времени. Обученный геном устойчив на невиданных трассах:
выживает до лимита кадров (score ≈ 11088 на 36 000 кадрах) при нуле бесполезных
прыжков.

## Требования

- Python 3.14+
- `playwright` + Chromium: `uv run playwright install chromium`
- `neat-python`, `numpy`
